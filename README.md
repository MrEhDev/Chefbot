# Chefbot 🧑‍🍳🤖

Chefbot es una aplicación web inteligente diseñada para acabar con la eterna pregunta de: *"¿Qué comemos hoy?"*. Funciona como tu planificador de menús semanal, recetario digital y generador de lista de la compra todo en uno.

## ✨ Características Principales

* **Generador Inteligente de Menús**: Configura los días, los comensales, tus dietas y elige un par de recetas que te apetezcan. Chefbot generará un menú balanceado al instante.
* **Filtros Dietéticos Estrictos**: Su algoritmo analiza los ingredientes de cada receta para garantizar que si seleccionas la dieta Vegetariana o Vegana, no se cuela ninguna carne ni derivado animal.
* **Importador Mágico de URLs**: Pega el enlace de una receta de blogs conocidos (como Pequerecetas) y Chefbot extraerá automáticamente los ingredientes, la imagen y los pasos.
* **Drag & Drop**: ¿No te convence el menú generado? Arrastra y suelta las recetas para intercambiarlas de día o pulsa el botón "Cambiar" para que el bot te sugiera otra alternativa instantánea.
* **Lista de la Compra Automática**: Agrupa automáticamente todos los ingredientes necesarios para tu menú y te permite ir tachándolos en el supermercado.
* **Totalmente Privado**: Tus menús, preferencias y recetas personalizadas se guardan directamente en tu navegador.

## 🛠️ Stack Tecnológico

* **React** + **Vite**: Para un rendimiento y experiencia de usuario ultra rápida.
* **Tailwind CSS**: Diseño responsivo y moderno, con un modo oscuro adaptativo y estilos "premium".
* **Zustand**: Gestión del estado global para mantener todo sincronizado (Menús, Catálogo, Lista de la compra) de forma sencilla y eficiente.
* **Lucide React**: Iconografía moderna.

## 🚀 Instalación y Uso

1. **Clona el repositorio**
   ```bash
   git clone https://github.com/tu-usuario/chefbot.git
   ```
2. **Instala las dependencias**
   ```bash
   npm install
   ```
3. **Inicia el servidor de desarrollo**
   ```bash
   npm run dev
   ```
4. **Construye para producción**
   ```bash
   npm run build
   ```
